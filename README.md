# Lattice Grid tutorial: a CRUD application on Node and DynamoDB

Source for the step-by-step series at
https://www.latticegrid.dev/docs/tutorials/. Each part is a folder with
everything that part asks you to paste or run.

| Part | What you build | Folder |
| --- | --- | --- |
| 1 | A DynamoDB table with demo data, a Node Lambda that reads it, and a web page that shows it in a grid | [`part-1/`](part-1/) |
| 2 | Add a product through the grid's built-in form and delete one from the right-click menu, both landing in DynamoDB | [`part-2/`](part-2/) (needs Lattice Grid 1.76.0) |
| 3 | Edit cells in place with optimistic write-back and revert, full screen, and the form rendered in a side panel | [`part-3/`](part-3/) (needs Lattice Grid 1.76.0) |

Download everything with **Code, Download ZIP**, or clone the repository.
Each part's README lists what you need and what it costs to run.
